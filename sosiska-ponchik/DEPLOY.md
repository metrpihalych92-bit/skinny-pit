# Инструкция по запуску и публикации Sausage Runner

## Локальный запуск

Игра представляет собой **один файл `index.html`** без зависимостей и сборки.

### Способ 1 — Открыть напрямую в браузере
1. Откройте файлы в проводнике: `output/5-нужно-создать-веб-игру-в-жанре-раннера-r/`
2. Дважды кликните по `index.html`
3. Файл откроется в браузере — игра запустится немедленно

> ⚠️ Некоторые браузеры блокируют `localStorage` при открытии через `file://`.
> Если рекорд не сохраняется — используйте локальный сервер (способ 2).

### Способ 2 — Локальный HTTP-сервер (рекомендуется)

**Python (встроен в ОС):**
```bash
cd "output/5-нужно-создать-веб-игру-в-жанре-раннера-r"
python -m http.server 8080
# Открыть: http://localhost:8080
```

**Node.js / npx:**
```bash
cd "output/5-нужно-создать-веб-игру-в-жанре-раннера-r"
npx serve .
# Открыть: http://localhost:3000
```

**VS Code:** установите расширение **Live Server** → правой кнопкой по `index.html` → "Open with Live Server"

## Управление

| Действие | Клавиша / Жест |
|---|---|
| Переключить линию влево | `←` |
| Переключить линию вправо | `→` |
| Прыжок | `ПРОБЕЛ` или `↑` |
| Пауза / Продолжить | `P` или `ESC` |
| Рестарт (на экране Game Over) | `ПРОБЕЛ`, `Enter` или `R` |
| Мобильный свайп влево/вправо | смена линии |
| Мобильный тап или свайп вверх | прыжок |

## Публикация в интернет

### Вариант 1 — GitHub Pages (бесплатно, рекомендуется)
1. Создайте репозиторий на GitHub
2. Загрузите `index.html` в корень репозитория
3. Зайдите в Settings → Pages → Source: `main` branch `/root`
4. Игра будет доступна по адресу: `https://<username>.github.io/<repo>/`

### Вариант 2 — Netlify Drop (быстрее всего)
1. Откройте [netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите папку с `index.html` в браузер
3. Получите публичный URL мгновенно (без регистрации)

### Вариант 3 — Vercel
```bash
npm i -g vercel
cd "output/5-нужно-создать-веб-игру-в-жанре-раннера-r"
vercel
# Следуйте инструкциям в терминале
```

### Вариант 4 — itch.io (для игр)
1. Зарегистрируйтесь на [itch.io](https://itch.io)
2. Создайте новый проект → тип: HTML
3. Загрузите ZIP-архив с `index.html`
4. Включите опцию "This file will be played in the browser"

## Технические детали

- **Файлов:** 1 (`index.html`)
- **Зависимости:** Three.js 0.160.0 загружается из CDN jsDelivr при первом запуске (~600 KB, кешируется браузером)
- **Размер:** ~42 KB (HTML + JS-код)
- **Браузеры:** Chrome 89+, Firefox 108+, Edge 89+, Safari 16.4+ (требуется поддержка ES Modules importmap)
- **Мобильные:** iOS Safari, Android Chrome (touch-управление встроено)
- **Хранение рекорда:** `localStorage` (локально в браузере пользователя)

> ⚠️ Для работы необходим интернет при первом запуске (загрузка Three.js). После кеширования игра работает офлайн.
