# Research: Pomodoro Timer с футуристичным неоновым интерфейсом

## Тип проекта
website (одностраничное веб-приложение / SPA)

## Описание идеи
Браузерный Pomodoro-таймер с полностью настраиваемыми параметрами: количество рабочих циклов,
длительность рабочих периодов и перерывов, автозапуск следующего периода. Интерфейс выполнен
в футуристичном неоновом стиле: чёрный или тёмно-фиолетовый фон, светящиеся элементы, тени,
эффект glow. Поддерживается переключение тёмной/светлой темы, звуковые уведомления об
окончании периодов, кнопки запуска и сброса таймера.

## Рекомендуемый стек

- **Frontend:** React 18 + TypeScript
- **Сборщик:** Vite
- **Стилизация:** CSS Modules или Tailwind CSS с кастомными CSS-переменными для неоновых эффектов
- **Состояние:** React useState / useReducer + useEffect (без внешних state-менеджеров, проект небольшой)
- **Звук:** Web Audio API (встроен в браузер, не нужны сторонние библиотеки и аудиофайлы)
- **Анимации:** CSS animations + SVG (stroke-dasharray / stroke-dashoffset для кругового прогресс-бара)
- **Хранение настроек:** localStorage (настройки и тема между сессиями)
- **База данных:** не нужна (всё хранится в localStorage)
- **Backend:** не нужен (полностью клиентское приложение)

## Обоснование выбора стека

**React + TypeScript + Vite** — оптимальный выбор для данного проекта по следующим причинам:
- Простой SPA без серверной части; React отлично подходит для компонентного UI
- TypeScript даёт типобезопасность для логики таймера (особенно важно для точных вычислений)
- Vite обеспечивает мгновенный dev-сервер и быструю сборку
- Множество open-source примеров pomodoro-таймеров на этом стеке (MatheusPMello, krau5/pomo)

**Web Audio API** вместо MP3-файлов:
- Нет зависимости от внешних файлов
- Синтез звука прямо в браузере через OscillatorNode + GainNode
- Гибкая настройка частоты и формы волны (sine/square)
- Полная поддержка во всех современных браузерах

**SVG circular progress** вместо CSS-only:
- Точное управление прогрессом через stroke-dashoffset
- Легко добавить neon-фильтры (SVG filter: feGaussianBlur + feColorMatrix)
- Анимация через CSS transition для плавности

**CSS Variables + box-shadow/text-shadow для неона:**
- Нет необходимости в дополнительных библиотеках анимации
- CSS Variables позволяют легко переключать тёмную/светлую тему
- Layered box-shadow (5-7 слоёв с увеличивающимся blur) создаёт реалистичный glow-эффект
- Пример: `box-shadow: 0 0 5px #a855f7, 0 0 10px #a855f7, 0 0 20px #a855f7, 0 0 40px #7c3aed`

## Ключевые функции для MVP

1. **Круговой таймер** — SVG-кольцо с анимированным прогрессом, отображение оставшегося времени в центре (MM:SS), неоновый glow на прогресс-кольце
2. **Управление таймером** — кнопки Start/Pause и Reset с неоновым hover-эффектом
3. **Настройки периодов** — длительность рабочего сессии (по умолчанию 25 мин), длительность короткого перерыва (5 мин), длительность длинного перерыва (15 мин)
4. **Настройка циклов** — количество рабочих сессий до длинного перерыва (по умолчанию 4)
5. **Автозапуск** — переключатель автоматического старта следующего периода после окончания текущего
6. **Индикатор цикла** — визуальное отображение текущего цикла (например, 4 точки / иконки томата)
7. **Звуковые сигналы** — синтезированный звук через Web Audio API при окончании каждого периода; возможность включить/отключить звук
8. **Тёмная / светлая тема** — переключатель; настройки сохраняются в localStorage; светлая тема сохраняет неоновую эстетику (тёмно-серый фон вместо чёрного, те же акценты)
9. **Сохранение настроек** — все пользовательские настройки автоматически сохраняются в localStorage
10. **Уведомление в заголовке вкладки** — обновление document.title с оставшимся временем, чтобы пользователь видел таймер в других вкладках

## Технические советы по реализации

### Точность таймера
- Не использовать `setInterval` напрямую — дрейф времени накапливается
- Рекомендуется: сохранять `startTime = Date.now()` и вычислять оставшееся время как разницу
- Шаблон: `remaining = duration - (Date.now() - startTime)`
- `setInterval` только для обновления UI (каждые 500ms достаточно)

### Web Audio API — синтез звука
```javascript
function playBeep(frequency = 880, duration = 0.3, type = 'sine') {
  const ctx = new (window.AudioContext || window.webkitAudioContext)();
  const oscillator = ctx.createOscillator();
  const gainNode = ctx.createGain();

  oscillator.connect(gainNode);
  gainNode.connect(ctx.destination);

  oscillator.type = type;
  oscillator.frequency.setValueAtTime(frequency, ctx.currentTime);

  gainNode.gain.setValueAtTime(0.5, ctx.currentTime);
  gainNode.gain.exponentialRampToValueAtTime(0.001, ctx.currentTime + duration);

  oscillator.start(ctx.currentTime);
  oscillator.stop(ctx.currentTime + duration);
}
```
- AudioContext нужно создавать после user interaction (требование браузеров)

## Риски и сложности

- **Точность таймера в фоновых вкладках** — браузеры throttle setInterval в неактивных вкладках; решение: использовать `Date.now()` для вычисления прогресса, а не счётчик тиков
- **Autoplay policy браузеров** — Web Audio API нельзя инициализировать до первого взаимодействия пользователя; AudioContext нужно создавать по клику (например, по кнопке Start)
- **Переключение тем** — важно сделать плавный transition (0.3s) для всех CSS-переменных чтобы избежать резкого мигания
- **SVG производительность** — фильтры SVG (особенно feGaussianBlur для glow) могут быть ресурсоёмкими; предпочтительнее использовать CSS filter: drop-shadow()
- **Адаптивность** — футуристичный дизайн с большим кольцом нужно адаптировать под мобильные экраны (min-width media queries, vw/vh единицы)
- **Сохранение состояния при перезагрузке** — при закрытии страницы таймер теряет состояние; можно сохранять pausedTimeLeft в localStorage, но не активный таймер (это edge-case)
