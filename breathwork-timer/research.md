# Research: Дыхательный тренажёр (Breathwork Timer)

## Тип проекта
website (pure front-end, статика)

## Описание идеи
Браузерный тренажёр дыхания с готовыми техниками (4-7-8, box breathing, Wim Hof, боевое дыхание) и кастомными таймингами. Анимированный круг визуализирует фазы вдоха/паузы/выдоха, Web Audio API генерирует тональные сигналы без файлов. Пользователь задаёт число циклов и запускает сессию — приложение ведёт его через весь процесс. Никакого бэкенда, никакой регистрации, работает в браузере.

|----------|-----|----------------------|
| Breathwork Tools | https://breathwork.tools/ | Разные частоты синус-тонов на каждую фазу (528/432/396 Hz) — красивая идея. Тёмный UI (#0a0e1a фон). Expanding orb + progress ring. Слабые стороны: Firebase + auth + paywalls перегружают простой инструмент |

| ZenMix Breathing Timer | https://zenmix.io/breathing-timer/ | Хороший выбор анимаций (круги, инь-янь, треугольник). Несколько звуковых тем. Слабые стороны: premium ограничения на точность, интерфейс перегружен опциями, не хватает фокуса |

### Вывод по аналогам
Все три решают задачу, но каждый грешит или сложностью (auth, paywalls), или бедностью фич (нет звука, мало техник), или перегруженностью UI. Пространство для чистого, лаконичного, бесплатного инструмента с хорошим UX — есть.

## Стек

- **Frontend:** Vanilla JS + HTML + CSS (никаких фреймворков — анимации и Audio API не требуют React)
- **Анимации:** CSS transitions + keyframes для круга; requestAnimationFrame для плавного прогресс-ринга (arc на Canvas или CSS conic-gradient)
- **Звук:** Web Audio API — OscillatorNode с разными частотами и GainNode для плавного fade in/out
- **Данные:** Захардкоженный JS-объект с 4-5 техниками; кастомные тайминги — в памяти страницы (не нужен localStorage)
- **Сборка:** Нет сборщика — один index.html, один style.css, один script.js; деплой на GitHub Pages / Netlify Drop
- **Шрифт:** Inter или системный стек sans-serif (не грузить лишнее)

## Дизайн-ориентиры
- Фон тёмный (~#0d0f14), акцентный цвет — приглушённый cyan/indigo (не кислотный)
- Круг: простой border-radius: 50%, анимация scale через CSS transition (ease-in-out)
- Прогресс фазы: тонкий conic-gradient или SVG circle stroke
- Текст фазы крупный («Вдох» / «Задержка» / «Выдох»), таймер обратного отсчёта рядом
- Выбор техники — карточки или горизонтальный список, без модалок

## План реализации

1. **Структура и данные** — создать index.html + style.css + script.js; объект `TECHNIQUES` с 4 техниками (name, description, phases: [{label, duration}], defaultCycles)

2. **UI: выбор техники и запуск** — верстка: список техник с кратким описанием, поле «циклов», кнопка Start; секция «свои тайминги» (4 инпута вдох/задержка1/выдох/задержка2 + кнопка применить)

3. **Анимированный круг** — CSS-переменная `--scale` управляет transform: scale(); JS меняет её при смене фазы; синхронный текст фазы и обратный отсчёт секунд через setInterval

4. **Прогресс-ринг фазы** — SVG circle с stroke-dashoffset, анимируется через requestAnimationFrame от 0 до 100% за duration фазы

5. **Web Audio API: тональные сигналы** — функция `playTone(freq, duration)` создаёт OscillatorNode + GainNode, плавный attack/release (0.05s), разные частоты: вдох 528Hz, задержка 396Hz, выдох 285Hz

6. **Логика сессии** — конечный автомат: idle → breathing (цикл фаз) → done; счётчик циклов, экран завершения с кнопкой «Снова»; мьют-кнопка для звука

7. **Полировка UX** — адаптив (mobile-first), hover/focus стили, плавный transition между экранами (opacity), короткое описание каждой техники перед стартом

## Риски
- **Web Audio на iOS Safari** требует запуска AudioContext внутри user gesture (click) — создавать контекст строго по нажатию кнопки Start, иначе звук не сработает
- **Wim Hof** включает задержку дыхания до 2+ минут — интерфейс должен корректно обрабатывать фазы длиной 0 (пропускать паузу) и очень длинные фазы без ощущения зависания
