# Skinny Pit — витрина микро-продуктов

## О проекте
Это публичный сайт-витрина: `index.html` в корне — главная страница со списком карточек,
каждая подпапка — отдельный опубликованный микро-продукт со своим `index.html`.
Живёт на GitHub Pages по адресу skinny-pit.ru.

## Откуда берутся продукты
Подпапки (`sosiska-ponchik/` и другие) публикует система ai-pipeline автоматически —
кнопка «Опубликовать» в интерфейсе Джарвиса копирует готовый проект сюда и добавляет
карточку на главную. Не редактируй эти подпапки вручную без необходимости — при следующей
публикации/обновлении из ai-pipeline содержимое подпапки перезапишется.

## Что можно менять здесь вручную
- Дизайн и текст главной страницы (`index.html` в корне)
- Порядок/оформление карточек на главной (между ними и `<!-- PROJECT_CARDS -->` в конце
  списка — маркер, куда ai-pipeline вставляет новые карточки; не удаляй его)
- Любые собственные страницы вне подпапок продуктов

## Стиль
Тёмная тема, лёгкий неон (акцент `#a78bfa`), тот же визуальный язык, что в интерфейсе
ai-pipeline (дизайн-система orbit): фон `#06060a`/`#0b0b14`, текст `#edecff`/`#9992b8`,
шрифты Inter + JetBrains Mono (моно — для технических подписей).

## Инфраструктура (не трогать без крайней необходимости)
- `.github/workflows/static.yml` — автодеплой на Pages при пуше в master
- `CNAME` — содержит `skinny-pit.ru`, обеспечивает работу кастомного домена
- DNS настроен на reg.ru (A-записи на GitHub Pages IP + CNAME для www)
- Вопросы по DNS/Pages/механизму публикации — решаются в окне ai-pipeline, не здесь

## Публикация изменений
Обычный git-репозиторий: `git add -A && git commit -m "..." && git push origin master`.
Pages пересоберётся автоматически за 1-2 минуты после пуша.
